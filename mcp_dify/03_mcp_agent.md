# Difyで行政手続データMCPに触れてみよう

ここでは、DifyからMCPサーバーに接続し、AIが外部データを利用する仕組みに触れていきます。  

デジタル庁の行政手続データを使って、AIから情報を検索・集計する体験をしてみましょう。

## 2. ハンズオン：Difyで行政手続データMCPを使ってみよう

### 2-1. Difyを立ち上げてMCP Serverを登録しよう

1. [Dify](https://cloud.dify.ai/)を開き、ログインします。

> <img src="https://i.gyazo.com/80e23d6a0fa6d7ee0a6e5014d7b8a25b.png" width="450">

2. 画面左側にある`連携`を選び、ツールの中の`MCP`をクリックします。

> <img src="https://i.gyazo.com/f153f04a15ad8dedc259411839823327.png" width="450">

3. `MCP サーバー（HTTP）を追加`ボタンをクリックします。

> <img src="https://i.gyazo.com/f4f056abbca8641d491cac25b51b8254.png" width="250">

4. 次のように設定し、入力できたら`追加して承認`ボタンをクリックします。

- `サーバーURL`：`講師が準備したURL`を入力します。  
- `名前`：`行政手続データ分析`
- `サーバー識別子`：`admin-procedures-mcp`
- `動的クライアント登録を使用する`のスイッチ：オフ  

> <img src="https://i.gyazo.com/75a372bcd0684258aa1f59fc08fd2056.png" width="200">

5. 画面右側に`認証済み`と表示され、次の4つのツールが含まれていることを確認できればOKです。

> <img src="https://i.gyazo.com/6787fc051e5434676784d84179ae8c5e.png" width="450">

### 2-2. Agentアプリを作成しよう

ここからは、MCP Serverのツールを利用するAgentアプリを作っていきます。

1. 左側にあるサイドバーの`スタジオ`をクリックし、`＋作成`ボタンをクリックします。

> <img src="https://i.gyazo.com/5b0b093e32dbcc091e298112c59b61ca.png" width="450">

2. `最初から作成`をクリックします。

> <img src="https://i.gyazo.com/7ea704e7d63ceda6a5c6d019c05c098b.png" width="250">

3. 基本的なアプリタイプから`エージェント`を選択します。   
エージェントが表示されていない場合は、`初心者向けの基本的なアプリタイプ`をクリックします。

> <img src="https://i.gyazo.com/9c21372634766f5b8c15c6898b2b110a.png" width="450">

4. アプリの名前へ`行政手続データ分析AI`と入力し、`作成する`ボタンをクリックします。

> <img src="https://i.gyazo.com/b9e4e8497c53705b3e3e0a0c4f3fc32a.png" width="450">

### 2-3. モデルとAgentを設定しよう

1. Agent編集画面のモデルを設定します。  
モデルプロバイダーから`Gemini`を選択し、モデルは`Gemini 3.5 Flash-Lite`を選択します。

> <img src="https://i.gyazo.com/74407c1ce574eb46c425d2dfe5c08d64.png" width="450">

2. 画面上部の`エージェント設定`ボタンをクリックし、最大反復回数を`3`に設定します。入力できたら、画面右下の`保存`ボタンをクリックして閉じます。

> <img src="https://i.gyazo.com/f5a22f70942365d2a7b8b35ca2649166.png" width="450">

> <img src="https://i.gyazo.com/8f74f07a02588357e237ef1f8d0ebc2c.png" width="450">

3. 左側の`プロンプト`欄に、以下をコピーして貼り付けます。

※ プロンプト：AIへの指示文章のこと

```text
あなたは行政手続データを分析するAIアシスタントです。

ユーザーの質問に応じて、利用可能なツールを使用し、行政手続データの検索・集計・分析を行ってください。

- 最初に利用可能なデータセットと、そのデータ構造を確認してください。
- 検索や集計を行った場合は、使用した条件と結果を分かりやすく説明してください。
- データに含まれていない情報は推測せず、確認できた事実に基づいて回答してください。
- データに含まれていない場合は「データがありませんでした」と回答するようにしてください。
```

> <img src="https://i.gyazo.com/103402f235709807bf660e0240f027ba.png" width="450">

4. `ツール`の`＋追加`をクリックします。

> <img src="https://i.gyazo.com/6a90b990990913d13a40fbbdf6ddf5c8.png" width="450">

5. `MCP`タブの中にある、登録した`行政手続データ分析`の`すべてを追加する`ボタンをクリックします。

> <img src="https://i.gyazo.com/24b2f9b0dfbb3067daff779904757c47.png" width="250">

6. 4つのツールがすべて追加され、次のような画面になっていればOKです。

> <img src="https://i.gyazo.com/c29c5a6f3d793c62f5f5144d933a6179.png" width="450">

### 2-5. 試してみよう

1. 画面右側のプレビュー画面で、以下の質問を入力して送信します。

```text
利用可能な行政手続データセットの名称、発行者、レコード数を教えてください。出典も示してください。
```

> <img src="https://i.gyazo.com/507db0c5eceb3cf7ccece3a9747935f0.png" width="450">

2. 以下のような返答が表示され、データを取得できていればOKです。

> <img src="https://i.gyazo.com/16aef4dbbaf7c0ea1fbbe755979ccf36.png" width="450">

3. 他の質問もしてみましょう。  
例えば、以下のような質問を入力して送信します。

```text
従業員を初めて雇用するときに必要になる行政手続を検索してください。
```

このほかにも、自分がこれまで質問していたことや、質問してみたいことを聞いてみましょう。

データを取得できていたら完了です！

## 3. Tips

### 3-1. うまく動かないとき

うまく動かない場合は、次の項目を確認してみましょう。

- MCP Server URLを再確認する
  - URLの末尾が`/mcp`になっているか
  - Codespacesが起動しているか（今回は講師側）

- DifyのMCP Server設定を開き、4つのツールが表示されているか確認する

- Gemini APIキーがDifyへ正しく登録されているか確認する
  - Geminiでうまく動かない場合は、[OpenRouterでAPIキー作成](./openRouter.md)も試してみる

- エージェント設定を見直す
  - Agentへ4つのツールを追加しているか
  - エージェントモードが`関数呼び出し`になっているか
  - 最大反復回数が`3`になっているか

- プロンプトが正しく貼り付けられているか確認する
- ポート8000の表示範囲が`Public`になっているか確認する

## 4. チャレンンジ

### 4-1. プロンプトを工夫してみよう

プロンプトへ指示を追加することで、回答の表示方法を変えることができます。

以下のようにどんな人が何を目的として使うかを考えて、指示を追加し試してみましょう。

- 回答の最初に結論を表示する
- 複数の手続を比較できるように表で整理する
- 申請の流れや確認事項を、順番が分かる箇条書きで表示する
- 使用した検索条件や出典を、回答の最後に表示する など


### 4-2. 集計や比較をしてみよう

MCPのツールを使うと、データの検索だけでなく、集計や比較もできます。  
以下のような質問を試してみてください。

```text
オンライン化されていない行政手続のうち、総手続件数が多いものを上位5件教えてください。
手続名、所管府省庁、総手続件数を表で示してください。
```

## 5. まとめ

今回は、DifyのAgentからMCP Serverへ接続し、外部の行政手続データを検索・取得しました。

MCPを利用すると、AIが持っている知識だけで回答するのではなく、外部のデータやツールを使って回答できるようになります。

ほかのMCP Serverやデータにも接続して、どんどん触れていきましょう。
