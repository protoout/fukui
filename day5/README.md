# n8n とは？
n8n はオープンソースのワークフロー自動化ツールです。プログラミング不要で、視覚的に Google Sheets や Slack、メール、データベース、生成 AI など普段使っているツール同士をつなげて面倒な作業を自動化できるソフトウェアです。  
パズルのようにツールをつなげられるサービスと考えてください。

# 実装

## まずはノードを並べる
1. n8n Form
まずはユーザーが入力するフォームを作成します。
`n8n Form` から `On new n8n Form event` を選択しフォームをつくりましょう。
編集する部分を以下に記載します。
- `Form Title`: 画像作成
- `Form Description`: つくりたい画像のテーマを入力してください
- `Form Elements > Label`: 画像のテーマ
- `Form Elements > Element Type`: Text input
以下の2つは `Add Attribute` を押して選んでください。
- `Form Elements > Custom Field Name`: imageTheme
- `Form Elements > Placeholder`: 例：ラッパを吹いている猫

大事なのは`Element Type`と`Custom Field Name`です。間違えがないようにしましょう。

2. Edit Transformation
続いてフォームに入力されたデータを加工するノードを準備します。
`Edit Transform` から `Edit Fields` を選択します。

ここで画面左側の`Execute Previous nodes`を押してみましょう。先ほど作成したフォームが立ちあがるはずです。画像のテーマを入れて `submit` しましょう。
すると`imageTheme`、`submittedAt`、`form Mode`という名前の3つの変数が出来上がります。これらを真ん中の`Drag input fields here or Add Field`にドラッグ&ドロップしましょう。

それぞれ、`{{ $json.imageTheme }}`のような値が入ればOKです。

> [!NOTE]
> `{{ }}` に囲まれた内容は、「変数として扱う」という明示的な指示となります。

3. OpenAI
加工したデータを生成 AI に渡します。
`OpenAI` から `Generate an image`
